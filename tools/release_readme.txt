GameMod: Hindi subtitles for your games
=======================================

KEEP THESE TOGETHER IN THE SAME FOLDER
    GameMod.exe
    subtitles (folder)

HOW TO USE
1. Close the game.
2. Double-click GameMod.exe.
   If Windows says "Windows protected your PC", click More info, then Run anyway.
3. Your games are listed on the left:
     Green tick = game found
     Red cross  = game not found. Click "Choose game folder" and pick the game's folder.
4. Click the game, then turn on the "Hindi Subtitles" switch.
5. Start the game and choose Hindi. For The Last of Us Part I:
     Options > Language > Subtitles > हिन्दी

TO GO BACK TO ENGLISH
Choose English in the same game menu. To remove the mod completely, close the game and
turn the switch off in GameMod.

GOOD TO KNOW
- You need your own copy of the game.
- Menus and in-game notes stay in English.
- If the switch turns itself off after a game update, turn it on again. Your subtitles are safe.
- If GameMod says Windows blocked it, right-click GameMod.exe and choose Run as administrator.
- If anything goes wrong, Verify Integrity in Steam puts the game back to normal.
